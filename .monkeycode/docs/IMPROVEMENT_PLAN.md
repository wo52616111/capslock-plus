# 项目改进计划

基于 2026-02-15 的代码审查结果，制定以下改进计划。

## 改进优先级

### 高优先级（必须修复）

#### 1. 修复 Excel 批量插入行列逻辑错误
- **严重程度**: 高
- **影响**: !f 功能会插入列而不是行，!d 功能会插入行而不是列
- **位置**: `CapsLock+.ahk:252-270`

#### 2. 评估管理员权限提升风险
- **严重程度**: 高
- **影响**: 脚本自动以管理员权限运行，存在安全风险
- **位置**: `CapsLock+.ahk:4-16`

### 中优先级（建议修复）

#### 3. 添加输入验证
- **严重程度**: 中
- **影响**: InputBox 没有验证用户输入，可能导致异常
- **位置**: `CapsLock+.ahk:255-257, 265-267`

#### 4. 添加边界检查
- **严重程度**: 中
- **影响**: 硬编码的边界值应使用配置项
- **位置**: `lib_keysFunction.ahk:29-52`

#### 5. 完善函数文档注释
- **严重程度**: 中
- **影响**: 代码可维护性差，难以理解函数用途

#### 6. 释放 COM 对象资源
- **严重程度**: 中
- **影响**: 可能导致内存泄漏
- **位置**: 多处 Excel COM 对象使用

### 低优先级（可选优化）

#### 7. 修复翻译 API 条件判断错误
- **严重程度**: 低
- **影响**: 重复判断同一个条件
- **位置**: `lib_ydTrans.ahk:20`

#### 8. 清理调试代码
- **严重程度**: 低
- **影响**: 影响代码整洁性

#### 9. 清理注释代码
- **严重程度**: 低
- **影响**: 增加代码复杂度

#### 10. 减少全局变量
- **严重程度**: 低
- **影响**: 增加代码耦合度
